# CiteCheck

Prose word count **391**

## Status and stack

CiteCheck is an offline citation-screening prototype. HTML and CSS present the interaction. Vanilla JavaScript normalises titles, compares them with two local records and keeps a reading list in memory until the page reloads. Two scripted examples stand in for chatbot output. The fixed catalogue stands in for live retrieval. A bibliographic provider and approximate matching policy are planned.

## Run or inspect

Download the repository and open index.html in a browser. Setup and API keys are unnecessary. DOI links require internet access.

- Load the matching example, check its DOI, add it to the reading list, then remove it.
- Load the fabricated example and check it. Choose **Edit title** and retry with *Fabrication and errors in the bibliographic citations generated by ChatGPT*.
- Search for *On human predictions with explanations and predictions of machine learning models: A case study on deception detection*. This real paper is outside the demo catalogue. The interface returns the same scoped miss as it does for a fabricated title.

Optional developer check with Node.js:

~~~sh
node check.cjs
~~~
